Prepared 2026-10-03. All seven library packages use the coordinated version
0.1.0-preview.15. Publication is separate from the version bump and main push.

## External-operation acquisition fix

AcquireAsync now requires the caller generation to match both the generation
captured when the operation was registered and the workflow run's current
generation. Previously, supplying a newer run generation could acquire an old
Requested handle after a restart. That acquisition now throws LeaseLostException
and leaves the handle's status, owner and captured generation unchanged.

The check and update share an immediate SQLite writer transaction. The
conditional update also binds the stored operation generation. The regression
Restart_RejectsCurrentGenerationForPreRestartHandle covers the newer-caller/old-
handle case; existing coverage retains rejection of stale callers.

Public signatures and SQLite schema version 5 remain unchanged. The standalone
repository operation does not supply Hufu authority or decision evidence.
The separate experimental Hufu/Zhinu start adapter and unfinished governed-host
recovery remain explicitly documented outside this preview's completion gate.
