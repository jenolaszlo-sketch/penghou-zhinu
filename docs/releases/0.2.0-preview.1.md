# 0.2.0-preview.1 candidate

This candidate adopts `Penghou.Workflow.Abstractions` `0.1.0-preview.2` and adds
per-attempt execution authorization, durable approval checkpoints, and independent
compensation declarations. It has no Hufu dependency. Read the
[host configuration and execution boundary](../workflow-authorization.md).

The new preview minor follows the [public API policy](../public-api-policy.md):
protected claim attempt accounting and durable approval introduce new state
transitions. Existing unenforced runs and public constructor signatures retain
their behavior. Existing compiled consumers are qualified separately.

SQLite schema changes from 5 to 6. Version 5 upgrades transactionally with additive
nullable columns and new authorization tables; existing rows remain explicitly
unprotected. Older schemas are rejected as before. Back up the database and
quiesce old workers before upgrading. Version 5 binaries reject the upgraded
database; do not run mixed worker versions or lower the schema marker to bypass
that check. Rollback requires restoring the backup. Authorization-aware stores
must implement the optional repository's fenced commit and dispatch validation.

Protected runs retain a versioned provider/profile binding. Removing the provider,
changing its mapping/profile or dropping required evidence fails closed. Reused
completed results are historical reconstruction and do not obtain a new execution
permission; result-disclosure policy remains host-owned. Orchestration callbacks,
loop bodies and native effects are outside activity preflight.

This file records a local release candidate, not a published package. Publication
remains the user's NuGet CI step after qualification and review. Hufu.Workflow
integration follows publication of the qualified Zhinu release.
